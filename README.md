# Nocturne

Dungeon crawler turn based game built in C++ because I was bored.

<img width="983" height="856" alt="Screenshot 2026-11-21 at 22 49 17" src="https://github.com/user-attachments/assets/cdef5bc0-8cd9-44cf-8b52-4b44200dc9b2" />

## How to run?

### Build

```bash
make
```

### Build & Run

```bash
make run
```

### Run after build

```bash
./dungeon
```

### Remove executable

```bash
make clean
```
